# Setforge

Из темы и свободных пожеланий продюсера — **3–5 вариантов коллекции по 10 карточек**.
Локальная форма заказа, страница результатов, отдельные PNG и ZIP. Тот же процесс
доступен через CLI и файловую очередь для любого агента или корпоративного исполнителя.

## Самый простой запуск: передайте это своему агенту

Дайте текст ниже своему агенту:

> Установи и запусти Setforge: https://github.com/dcdmtst/setforge.
> Сначала спроси меня, в какую папку его установить. После ответа скачай
> репозиторий в выбранную папку: используй Git, а если его нет — скачай ZIP
> https://github.com/dcdmtst/setforge/archive/refs/heads/main.zip и распакуй.
> Не перезаписывай существующие файлы. Прочитай SETUP_AGENT.md в скачанном
> репозитории и выполни его инструкции. Подключение эталонов тоже возьми на себя:
> спроси, какие изображения использовать и где они лежат или как их получить;
> нужные файлы настроек подготовь сам. В результате дай мне ссылку на работающую
> локальную страницу заказа и результатов со скачиванием ZIP. По умолчанию
> используй доступный тебе imagegen без дополнительных денежных расходов.
> После настройки обрабатывай заказы из страницы по AGENTS.md. Если в твоём
> окружении недоступна необходимая возможность, объясни, что именно требуется.

Агент установит зависимости в отдельное окружение, запустит сервер и даст ссылку
на страницу. Для стиля нужны **ваши локальные эталоны**: чужие игровые материалы
и результаты экспериментов в репозитории не распространяются.
Агент сам спросит об изображениях и подготовит пакет эталонов. Создавать JSON
и style.md вручную не нужно. Skill не содержит скрытой базы из 160 изображений.

Для шрифта Lithos Pro Black агент подключает ваш лицензированный локальный OTF/TTF
по [инструкции подключения шрифта](docs/typography.md). Файл шрифта не распространяется
через GitHub. Если его нет, агент явно сообщает, что оформление пока нейтральное.

## Подключить эталоны или начать проект с другим стилем

Если Setforge уже установлен, дайте агенту:

> Подключи мои эталоны к Setforge. Используй установленный Setforge из
> https://github.com/dcdmtst/setforge; если папка установки неизвестна — спроси
> меня. Прочитай docs/reference-pack.md. Спроси, какие изображения использовать
> и где они находятся. Сам подготовь пакет, описание стиля и настройки, подключи
> их к проекту и дай ссылку на страницу заказа. Существующие заказы сохрани.

Для другого стиля команда агенту: **«Создай новый проект с новым стилем»**.
Полный текст, который можно ему передать:

> Создай новый проект Setforge с новым стилем. Репозиторий:
> https://github.com/dcdmtst/setforge. Если Setforge ещё не установлен, сначала
> спроси папку установки, скачай его и выполни SETUP_AGENT.md. В установленном
> Setforge прочитай .agents/skills/collection-set-pipeline/SKILL.md и раздел
> «Новый проект с новым стилем» в docs/reference-pack.md. Спроси, где создать
> новый проект, какие изображения взять за эталоны и какие есть пожелания
> к стилю. Сам подготовь пакет и описание стиля, создай отдельный проект
> с отдельной папкой заказов и открой его страницу. Старый проект, его эталоны,
> персонажей и результаты сохрани. Генерацию картинок пока не запускай.

В режиме встроенного imagegen агент должен оставаться активным: страница создаёт
заказы в очереди, но не может разбудить завершивший ответ чат. Для постоянной работы
подключите командных/API-исполнителей. Установка Codex CLI сама по себе не гарантирует
доступ к встроенному imagegen. Ключ OpenAI API и подписка Codex — разные способы доступа.

## Самостоятельная установка

Нужен Python 3.11+. В папке репозитория:

```text
python scripts/setup.py --style-pack PATH_TO_YOUR_STYLE_PACK --start --open
```

Windows: если `python` отсутствует, попробуйте `py -3`. macOS/Linux: `python3`.
Без `--style-pack` страница тоже откроется, но создание заказов будет заблокировано
до импорта эталонов. [Формат пакета](docs/reference-pack.md).

После установки CLI находится в `.venv/Scripts/setforge.exe` на Windows,
`.venv/bin/setforge` на macOS/Linux. Ниже `setforge` означает эту команду.

```text
setforge doctor --project .setforge/project
setforge run --project .setforge/project --brief examples/brief.json --run .setforge/runs/example
```

Код 3 означает ожидание исполнителя/решения, а не готовые картинки. Продолжение:
[CLI и CI](docs/cli-ci.md), [работа без Codex](docs/without-codex.md).

## Что проверяется

Состав и пожелания → английские названия → категории, звёзды и персонажи →
канон → арт → независимая приёмка карточек → целые наборы → экспорт.
Приёмка: **Q95 ≥ 93.5 без округления + все обязательные проверки**.
До трёх переделок после исходника. Плато требует смены способа исправления.
Непринятая карточка после лимита отбраковывается; остановка не считается приёмкой.

По умолчанию два художника и главный арт-директор, плюс координатор.
Число исполнителей настраивается. Автор не принимает ни одну версию своей карточки.
Формальная проверка JSON не заменяет визуальную оценку.
