# Веб-режим

Установка: README.md или SETUP_AGENT.md. Запуск:

```text
setforge ui --project .setforge/project --runs .setforge/runs --port 8840
```

Откройте http://127.0.0.1:8840/. Форма принимает тему, свободные пожелания и
3–5 вариантов (по умолчанию 3). Кнопка создаёт настоящий заказ; список показывает
готовность и ведёт в отчёт. Без эталонов форма объясняет, что нужно импортировать.
В файловом режиме нужен активный агент; сервер не вызывает встроенный imagegen
сам. Для постоянной обработки настройте внешних workers.

Отчёт показывает все варианты, даже если арт ещё не готов. Названия на английском;
переключатели названий, рамок, звёзд и итогового вида включены по умолчанию.
Число звёзд видно над карточкой. Проверка подписи не уменьшает шрифт.
Локальный шрифт проекта подключается через `font-configure`: см.
[typography.md](typography.md). Новые заказы используют один и тот же шрифт
в проверке названий и в отчёте. В автономном HTML остаются готовые надписи,
поэтому получателю не нужно устанавливать шрифт.
Звёзды используют оригинальные группы из UI-референса: 1–4 в ряд, пять —
по дуге с меньшими повёрнутыми крайними звёздами. Масштаб и перекрытие верхней
рамки считаются относительно ширины карты. Это готовые PNG, не Unicode,
перерисованная SVG-иконка или приблизительные повороты CSS. Эти же ресурсы
встроены в автономный HTML и ZIP, поэтому соединение с сервером не требуется.

В конце — статусы приёмки, причины отклонения, хронология и Gantt. Список заказов
обновляется автоматически; открытый отчёт обновите в браузере. Кнопка «Скачать ZIP»
появляется у завершённого заказа. При скачивании полнота, приёмка и хеши проверяются
повторно: устаревший статус не разрешит неполную выдачу. ZIP можно распаковать и
открыть report.html как обычный автономный файл.

Сервер слушает только 127.0.0.1, проверяет Host/Origin и пути файлов. Это персональная
локальная панель без логина, не публичный сервер. Не выставляйте её в интернет.
Открыв отдельно HTML-форму из пакета, можно скачать JSON-бриф для CLI. Это офлайн-
режим формы: генерации в нём не запускаются.
