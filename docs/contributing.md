# Изменения через PR

Ветка `main` защищена активным правилом репозитория:

- Только через pull request.
- Минимум один аппрув; обязательно от владельца `@dcdmtst`.
- Новые изменения сбрасывают прежний аппрув.
- Обсуждения должны быть закрыты перед объединением.
- Прямой push, force push и удаление `main` запрещены; исключений для
  администраторов, владельца и приложений нет.

`.github/CODEOWNERS` назначает владельца на все файлы, включая сам CODEOWNERS,
инструкции агентов и CI. Изменение этого файла также требует его аппрува.

Порядок: отдельная ветка → коммит → PR в `main` → проверка владельцем →
объединение. Агент готовит изменения и PR, но не выдаёт себе аппрув от лица
владельца и не ослабляет правила ради завершения задачи.

GitHub запрещает автору PR одобрять собственный PR. Поэтому PR, созданный
самим `dcdmtst`, не сможет пройти правило единственного владельца. Автором
должен быть другой разрешённый участник или бот; владелец проверяет со своего
аккаунта. Другая подпись коммита не меняет автора PR и не решает эту проблему.

Владелец технически может изменить настройки защиты; правило запрещает обход
при push/merge, но не отнимает у него административное управление репозиторием.
При переименовании владельца или передаче репозитория обновите CODEOWNERS
с согласованием действующего владельца.

CI запускает офлайн-тесты и аудит исходников. Его наличие не заменяет аппрув.
Политика производства карточек и порог Q95 от этого изменения не меняются.
