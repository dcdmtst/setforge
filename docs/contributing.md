# Доступ к репозиторию

Репозиторий публичный: читать, скачивать и создавать свои форки может любой.
**Писать в сам репозиторий может только владелец `@dcdmtst`.** Публичность
не предоставляет другим людям право push, изменения файлов или объединения PR.

Владелец может коммитить напрямую или работать через PR. Обязательных PR и
отдельного аппрува нет. Защита `main` от force push и удаления сохраняется.

Другой пользователь может предложить изменения через PR из своего форка.
Это предложение, а не изменение нашего репозитория: объединить его может
владелец. Записи в CODEOWNERS только направляют запросы на ревью и не выдают
права записи.

Не добавляйте участников, приглашения или deploy keys с правом записи без
явного решения владельца. GitHub Actions по умолчанию имеет доступ на чтение
и не может одобрять PR. Приложения и инструменты, которым сам владелец выдал
доступ от своего аккаунта, действуют в пределах этого разрешения.
