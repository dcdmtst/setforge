# Шрифт подписей и заголовков

Для оформления, близкого к исходным примерам, выбран **Lithos Pro Black**.
Это визуальная идентификация по форме букв, а не найденные метаданные исходников.
Полный OTF/TTF нужен локально, с лицензией на ваше использование.

Готовый текст для агента:

> Подключи Lithos Pro Black к моему проекту Setforge. Сначала найди уже установленный
> лицензированный файл или спроси, где он лежит. Выполни docs/typography.md сам.
> Не покупай шрифт, не публикуй его файл и не заменяй его похожим без моего решения.
> Проверь названия тем же шрифтом, которым будет нарисован результат.

## Подключение

Если локального файла нет, агент сначала проверяет доступ к
[Lithos в Adobe Fonts](https://fonts.adobe.com/fonts/lithos). Вход в Adobe,
добавление начертания Black в аккаунт и его установка — разные шаги.
Для использования вне приложений Adobe нужен официальный Creative Cloud desktop:
в нём необходимо установить шрифт для других приложений. Покупки и пробные платные
подписки без отдельного решения пользователя не запускаются.

Успех в браузере «шрифт добавлен» ещё не означает подключение к Setforge.
Агент проверяет доступность лицензированного OTF/TTF локальному рендереру,
его семейство и начертание. Если установленный через Adobe шрифт не доступен
как разрешённый для такого использования файл, агент сообщает это ограничение;
не извлекает веб-шрифт из предпросмотра и не объявляет подключение успешным.

Агент выполняет через установленный Setforge:

```text
setforge font-configure --project PROJECT --font PATH_TO_LICENSED_OTF_OR_TTF
setforge font-configure --project PROJECT
```

Первая команда проверяет файл, сохраняет его путь, реальное семейство, начертание
и SHA256 в локальном `PROJECT/typography.json`. Сам файл не копируется.
Вторая показывает выбранное оформление. Новые заказы фиксируют его в
`inputs/typography.json`; смена настройки проекта не меняет старые заказы.

Если файл недоступен или изменился, проверка останавливается с понятной причиной.
Подстановка Aileron вместо явно выбранного шрифта не допускается. У проектов,
которым шрифт ещё не подключили, остаётся явно обозначенный нейтральный Aileron.
Это не проверенная установка Lithos Pro Black.

Вместимость проверяется до арта: карточка — 18 px / 160 px; заголовок — 31 px /
850 px. Один масштаб для всего шрифта, естественная ширина и кернинг, исходный
регистр букв. Длинное слово не уменьшается. Переполнение требует правки названия.

## Существующий отчёт

Чтобы явно переоформить конкретный готовый заказ:

```text
setforge font-configure --run RUN --font PATH_TO_LICENSED_OTF_OR_TTF
setforge nameplate-check --run RUN
setforge export --run RUN
```

Это создаёт `presentation-typography.json`, не переписывая исходный бриф,
решения приёмки или PNG. Непоместившиеся подписи блокируют готовый ZIP.
В отчёт и ZIP встроены растровые надписи, поэтому получателю не нужен шрифт.
Файл шрифта и локальный путь в поставку не попадают.

## CLI, CI/CD и другие исполнители

```text
setforge nameplate-check --plan PLAN_JSON --project PROJECT
```

На другой машине задайте `SETFORGE_FONT_PATH` к лицензированному локальному файлу
с тем же SHA256. Это перенос пути, не смена шрифта. Одновременные проекты используют
собственные сохранённые профили, без глобального переключателя оформления.

Для серверной установки и распространения требуется соответствующая лицензия.
Обычная подписка Adobe Fonts не разрешает передавать файл шрифта вместе с проектом,
встраивать его в приложение или устанавливать на сервер: см.
[условия использования Adobe Fonts](https://helpx.adobe.com/fonts/web/font-licensing/font-licensing.html).
Поэтому коммерческий шрифт и растровый алфавит не включены в публичный репозиторий.
Установка шрифта выполняется только после предоставления подходящего локального файла;
ссылка на Adobe и найденное название семейства не заменяют его наличие.
