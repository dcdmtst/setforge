# Выбор и установка шрифта

По умолчанию запрашивается **Lithos Pro Black**. Это визуальная идентификация
исходников по форме букв, а не найденные метаданные. Файла Lithos нет в репозитории,
HTML или ZIP. Дефолтный **Aileron** доступен из Pillow без отдельной установки.

Готовый текст для агента:

> Выбери Lithos Pro Black для моего проекта Setforge. Проверь установленные шрифты.
> Если его нет, спроси: установить или использовать дефолтный Aileron. Следуй
> docs/typography.md: покажи инструкцию для моей ОС и предложи попытку автоустановки.
> Не покупай шрифт и не публикуй его файл. Проверь названия фактическим шрифтом.

## Форма заказа

В проекте есть параметр `"font": "Lithos Pro Black"`. Поле «Какой шрифт использовать?»
показывает установленные варианты и позволяет ввести название другого шрифта.
Выбор заказа перекрывает настройку проекта. ОС определяется у сервера Setforge:
при локальной установке это система пользователя.

Если шрифт отсутствует, при открытии страницы и перед заказом появляется выбор:
**Установить шрифт** или **Использовать дефолтный**. Второй вариант сохраняет Aileron
для этого заказа. Первый открывает инструкции под текущую ОС:

- **ОК (установлю сам)** закрывает окно. Заказ ещё не создаётся; поля сохраняются.
  После установки нажмите «Проверить установку» или снова создайте заказ.
- **Попробовать установить автоматически** устанавливает указанный лицензированный
  локальный OTF/TTF в пользовательскую папку шрифтов. Без файла для Lithos открывает
  официальный способ установки Adobe и, если доступен, Creative Cloud desktop.
  Вход, новые условия и оплату программа за вас не подтверждает.
  Открытая страница Adobe не объявляется успешной установкой: доступ проверяется
  отдельно. Если попытка не завершилась, можно установить вручную или выбрать Aileron.

## Ручная установка

**Windows и macOS, через Adobe:**

1. Установите [Creative Cloud desktop](https://www.adobe.com/download/creative-cloud)
   и войдите в Adobe.
2. На странице [Lithos](https://fonts.adobe.com/fonts/lithos) добавьте Black.
3. В Creative Cloud откройте Fonts → Added fonts → Lithos Pro Black → Install
   для использования в других приложениях. См. [инструкцию Adobe](https://helpx.adobe.com/creative-cloud/apps/integration-with-other-apps/manage-fonts/install-fonts.html).
4. Вернитесь в Setforge и нажмите «Проверить установку». Добавление в аккаунт
   само по себе не означает доступности локальному рендереру.

**Если есть отдельно лицензированный файл:** Windows — правой кнопкой по OTF/TTF →
«Установить». macOS — открыть в Font Book («Шрифты») → «Установить шрифт».
Linux — поместить файл в `~/.local/share/fonts` и выполнить `fc-cache -f`.
Creative Cloud desktop для Linux не предусмотрен: нужен отдельный файл или Aileron.
Не запускайте покупку/платную пробную подписку без отдельного решения пользователя.

## CLI и проект

```text
setforge init --project PROJECT --font "Lithos Pro Black"
setforge font-configure --project PROJECT --family "Lithos Pro Black"
setforge font-configure --project PROJECT --font LICENSED_FONT_FILE
setforge font-configure --project PROJECT --neutral
setforge font-configure --project PROJECT
setforge run --project PROJECT --theme "Board Games" --run NEW_RUN --font "Lithos Pro Black" --missing-font default
setforge font-install --project PROJECT --font "Lithos Pro Black"
setforge font-install --project PROJECT --font "Lithos Pro Black" --automatic --source LICENSED_FONT_FILE
```

`--family` сохраняет название; `--font` у font-configure связывает внешний файл,
не копируя его. Команда без выбора показывает эффективное оформление.
`run --font` перекрывает `font` в JSON-брифе и настройку проекта. Офлайн-форма
и `brief --font` сохраняют выбор в JSON. Системные шрифты ищутся по реальному
семейству/начертанию; неподдерживаемые/недоступные файлы не считаются установленными.

В интерактивном терминале при отсутствии шрифта задаётся вопрос. Без терминала
(CI/агент) по умолчанию используется Aileron с предупреждением; явный аргумент —
`--missing-font default`. `--missing-font install` и неинтерактивный `ask` возвращают
JSON с инструкциями и кодом 4 (нужен выбор/установка), не создавая заказ.
`font-install` без `--automatic` только показывает инструкции.

## Проверка названий и существующие заказы

Фактический шрифт, начертание, SHA256 и локальный путь фиксируются в
`inputs/typography.json`. Публичные метаданные не содержат пути. Выбранный Aileron
остаётся шрифтом заказа и после установки Lithos. Для другой машины можно указать
`SETFORGE_FONT_PATH` к локальному лицензированному файлу с тем же SHA256.

Если сохранённый шрифт пропал или изменился, процесс использует Aileron, явно
помечает fallback в метаданных/отчёте и заново проверяет вместимость. Нехватка
шрифта не обрывает процесс. Не поместившееся название требует правки.
Проверка и вывод используют одинаковые пиксели: карточка 18 px / 160 px,
заголовок 31 px / 850 px. Масштаб фиксирован; длинные слова не уменьшаются.

```text
setforge nameplate-check --plan PLAN_JSON --project PROJECT
setforge font-configure --run RUN --font LICENSED_FONT_FILE
setforge nameplate-check --run RUN
setforge export --run RUN
```

Явная смена оформления готового заказа создаёт `presentation-typography.json`,
не изменяя бриф, PNG и решения приёмки. В HTML/ZIP входят растровые надписи;
получателю не требуется шрифт. Локализации и loc QA — out of scope.

## Лицензия

Нужна лицензия на ваше использование. Обычный доступ Adobe Fonts не разрешает
распространять файл, встраивать шрифтовое ПО в приложение или ставить его на сервер:
см. [условия Adobe Fonts](https://helpx.adobe.com/fonts/web/font-licensing/font-licensing.html).
Сервер/CI требует подходящей собственной лицензии либо Aileron. Коммерческий файл,
веб-шрифт из предпросмотра и растровый алфавит не включаются в публичный проект.
