# Запуск без Codex

Setforge — обычный Python CLI и локальный сервер. Codex не обязателен.

1. Передайте своему агенту [текст установки из README](../README.md#самый-простой-запуск-передайте-это-своему-агенту).
   Он спросит папку установки, скачает Setforge и выполнит SETUP_AGENT.md.
2. Агент спросит об изображениях, сам подготовит и подключит эталоны, проверит
   доступный генератор и будет обрабатывать файловую очередь.
3. Если агент не поддерживает skills, он читает те же инструкции как обычные
   файлы. Если нет независимых субагентов, нужен отдельный визуальный исполнитель
   или человек для приёмки. Автор не принимает собственную работу.
4. Для постоянного сервиса реализуйте исполнителей `command` либо внешний
   worker, который читает задания, обновляет аренду и отдаёт ответ. См.
   [parallel-workers.md](parallel-workers.md) и [cli-ci.md](cli-ci.md).

Кнопка формы создаёт заказ. Генерация начнётся, когда его возьмёт активный
исполнитель. Без него будет честный статус ожидания. Наличие веб-страницы не
подразумевает доступ к моделям. Можно также обойтись JSON-брифом и CLI без браузера.

Платформа и генератор сменные; критерии приёмки, все варианты, история и
манифест остаются общими. Бесплатный инструмент не считается доступным только
потому, что у сервиса существует бесплатный тариф.

Чтобы подключить эталоны, передайте агенту [готовый текст](reference-pack.md)
и ответьте на его вопросы об изображениях. Пакет он подготовит сам. В skill и репозитории нет скрытой
базы из 160 картинок; один текстовый гайд не заменяет изображения.
У файлового художника используйте [image-start/image-finish](image-execution.md):
они подбирают входы под лимит и записывают служебные данные без ручного JSON.
Для нового стиля скажите агенту **«Создай новый проект с новым стилем»**;
[полный текст и порядок работы](reference-pack.md#новый-проект-с-новым-стилем).

Независимый ревьюер возвращает construction_review по точной схеме задания:
целое/части, соединения, механизм, опоры, перспектива и контакт персонажа.
Неубедительная конструкция требует переделки независимо от общего балла.
Это общий контракт CLI, а не возможность только Codex; см. [приёмку](art-acceptance.md).
