# Английские названия до арта

Гейт выполняется после составления вариантов и до генерации изображений.
Название должно точно описывать предмет или видимый сюжет и помещаться в
реальную плашку. Одно-два слова — ориентир исходных референсов, не доказательство
размещения. Количество символов не заменяет измерение пикселей: WWWW шире IIII.
Локализации и loc QA — out of scope; проверяется исходный английский текст.

Для канонического отчёта фиксированы две независимые полосы:

| Подпись | Высота видимых букв | Доступная ширина |
|---|---:|---:|
| Карточка |18px|160px|
| Название сета |31px|850px|

Размеры задаются политикой проекта до проверки. Они не увеличиваются и не
уменьшаются в зависимости от конкретного слова. Масштабирование всего превью
не должно превращаться в индивидуальную подгонку длинных подписей.

Если строка шире плашки, сначала переписать английское название, сохранив точность
и естественный язык, затем измерить повторно. Если ясного точного короткого
названия нет, заменить концепцию карточки до арта и повторить проверки состава,
категории и редкости. Не подгонять шрифт, не ставить многоточие, не обрезать
буквы и не расширять плашку ради успешного результата.

Проверка не исправляет тексты сама. Названия должны быть естественными,
точными и короткими; одинаковая длина в символах не гарантирует одинаковую ширину.

## Измерение и оформление

Измеряем тем же рендерером, который рисует итоговую подпись. Публичная версия
использует нейтральный шрифт Aileron, встроенный в Pillow, и собственные SVG-звёзды.
Игровой атлас букв не распространяется. Измерения относятся к этому оформлению;
при смене шрифта повторите гейт. Размер отдельного длинного слова не уменьшается.

Неизвестные символы нельзя пропускать, заменять системным шрифтом или считать
нулевой шириной. Диагностическая оценка по метрикам допустима, но не даёт pass.
Нужны проверенные буквы/метрики либо другое корректное английское название.

## API и аудит

`setforge.nameplate.preflight(plan, policy, measurefn)` возвращает общую проверку
и отдельный результат для каждой подписи. Функция не меняет plan и не пишет файлы.
`measurefn(text, target_height)` возвращает естественную ширину или словарь с
width; поддерживается и однопараметрический callback, если он уже использует
нужный фиксированный размер. Для итогового отчёта передавать настоящий рендерер.

```python
from setforge.nameplate import DEFAULT_POLICY, preflight
from setforge.ui_skin import measure_label

result = preflight(plan, DEFAULT_POLICY,
                   lambda text, height: measure_label(text, height))
```

Политика: version1, target_height18, available_width160,
set_target_height31, set_available_width850. Дополнительный список
producer_flagged_labels содержит ключи вида variant/card или set:variant:
они остаются fail/pending даже если ширина проходит, пока замечание не решено.

Результат содержит verdict, read_only, fit_to_width=false, labels и failed_labels.
У подписи есть key, kind, text, target_height, available_width, measured_width,
measurement_complete, unsupported_characters, reasons, verdict и next_action.
Происхождение измерения сохраняется в measurement_source; также сохраняются
font_file_recovered и case_rescaled, если их вернул растровый рендерер.
Граница проверяется без округления: ширина160 проходит,160.0001 уже нет.
Пустые/многострочные тексты и неанглийское письмо блокируются; естественность
английского и соответствие предмету остаются редакторской проверкой.

Для независимого инструмента можно передать явные метрики:

```python
metrics = {"advance": {"W": 14, "I": 4, " ": 6},
           "baseline_height": 18, "tracking": 1,
           "unknown_advance": 18}
```

Метрики масштабируются одинаково к фиксированной target_height; tracking
добавляется только между символами. Без unknown_advance диагностический fallback
берёт максимум высоты базовых букв и известных advance. Любой fallback помечается
как incomplete и не принимает строку. Подмена текста, изменение высоты, shrink,
ellipsis, crop или widening в данных измерения также блокируют pass.

```text
setforge nameplate-check --run PATH_TO_RUN
```

Команда служит аудитом и не меняет завершённый запуск. Для новых запусков
положительная проверка названий обязательна до арта; историческим результатам
не приписывается проверка, которой тогда не было. После сборки отчёта остаётся
визуальная проверка настоящей плашки: метрики не проверяют контраст, соседние
элементы интерфейса и качество исходного английского сами по себе.
