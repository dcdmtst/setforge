# Сменные генераторы

По умолчанию — встроенный **imagegen активного агента**, файловые задания.
Это не имя модели OpenAI API. Доступ проверяется в конкретном окружении:
создание PNG, редактирование существующего PNG, несколько референсов, возможность
сохранить настоящий результат. Установленный Codex CLI не доказывает этот доступ.

У imagegen лимит 5 входных изображений, включая эталоны, канон и edit target.
Подготовку под этот лимит и служебные записи выполняют `prepare-job`,
`image-start`, `image-finish`; [порядок работы](image-execution.md).
Размер всей локальной базы эталонов этим лимитом не ограничивается.

## Необязательная проверка

```text
setforge generators --project .setforge/project
```

Команда проверяет конфигурацию, наличие исполняемых файлов и переменных с
ключами. Значения ключей не выводит; моделей не вызывает. По умолчанию
imagegen имеет статус `runtime_check_required`. Агент может явно записать
проверенный по своему инвентарю файл возможностей:

```json
{"tools": [{"id": "imagegen", "generate": true, "edit": true, "reference_images": true}]}
```

Передайте его через `--capabilities capabilities.local.json`. Статус
`agent_confirmed` — декларация возможностей, **не результат генерации**.

Для сравнения доступных инструментов:

```text
setforge probe-generators --project .setforge/project --out .setforge/probe.json
```

Команда сохраняет одинаковые задания на предмет, сценку и редактирование,
референсы с хешами и контракт сравнения. **Пробный тест выполняет агент**, а не
эта команда. Только по явному запросу пользователя и без дополнительных денег.
Сравниваем принятую картинку, общее время с исправлениями, число переделок и
расходы. Независимый ревьюер использует ту же шкалу и порог 93.5. Автосмены модели
нет. Отсутствующие инструменты помечаются недоступными, не заменяются заглушками.

## Адаптеры

Роли `planner`, `reviewer`, `image` в локальном `project.json`:

- `files`: JSON-запросы, активный агент или ваш внешний worker.
- `command`: список аргументов без shell; `{request}`, `{response}`, `{python}` заменяются локальными путями. Команда должна вернуть
  ответ по схеме и настоящий файл. См. src/setforge/providers.py.
- `codex`: текстовые задания через установленный CLI, **не арт**.
- `chat-completions`: явно настроенный совместимый текстовый API.
- `image-cli`: необязательный OpenAI SDK-адаптер для арта, установка
  `pip install '.[openai-image]'`, явные модель и ключ в переменной окружения.
  API может тарифицироваться отдельно; нулевой бюджет не даёт разрешения на оплату.

Для бюджета 0 командный/API исполнитель должен быть явно отмечен `zero_cost:true`
с `estimated_cost:0`. Эта декларация не проверяет тариф провайдера: интегратор
обязан подтвердить бесплатность. Платные конфигурации не нужны для запуска по
умолчанию. Локальные модели тоже возможны через `command`; веса не скачиваются
автоматически. Подробный контракт вызова: [CLI и CI](cli-ci.md).
