# Collection art rules

Create an original object or character-scene illustration, one image per card. Match the supplied
reference illustrations: polished volumetric casual art, chunky readable forms,
soft modelling, clean saturated colours, distinct materials, organised details.
One dominant semantic group; secondary objects support it. Preserve the silhouette
at thumbnail size. Separate subject and background through value and colour.
Use lighting appropriate to the scene, material-specific highlights and contact
shadows. Neither an isometric camera nor a fixed lighting direction is mandatory.

Vary composition and backdrop within a set; keep rendering quality consistent.
Background categories: 1 floating object on a simple gradient/pattern;
2 object on a simple surface, simple backdrop; 3 recognisable material surface,
simple backdrop; 4 object integrated into an environment, remaining the focal point.
All four categories must occur in each set; there is no prescribed quota.
Category 5 is a golden scene with one or two key characters in an environment;
follow the current explicit character policy. Stars are separate metadata.

Reference images may contain game UI. Use their art as style evidence only.
Do not reproduce frames, stars, labels, watermarks, windows or card layouts.
Stars are assigned in metadata as ordinal rarity labels; do not infer drop rates.
Gold-coloured objects are allowed. Golden cards feature the game's key cast,
but ordinary cards may feature characters too. Never infer gold from character
presence or a character ban from a no-gold rule. Follow the explicit cast policy.
Ordinary animals/objects are not automatically golden cards.

A set is held together by a situation, activity or place. A sequential story is
optional. Cover distinct semantic roles and give generic props thematic context.
Variants should differ in interpretation and composition, not just palette.
Use new genre-specific motifs without copying recognisable film franchises.

Entity identity is preserved only for intentional recurring objects/characters.
Canon images and invariants override incidental variation. Keep the listed
invariants and vary only what is allowed. Generated revisions are never style
references in place of the original reference pack.
